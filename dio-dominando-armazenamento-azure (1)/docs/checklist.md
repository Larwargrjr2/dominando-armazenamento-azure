# Checklist de Evidências

Após executar o laboratório, registre evidências reais:

- [ ] Resource Group criado.
- [ ] Storage Account criada.
- [ ] Container privado criado.
- [ ] Blob enviado.
- [ ] Blob listado.
- [ ] Blob baixado.
- [ ] Conteúdo validado.
- [ ] Testes executados com sucesso.
- [ ] Recursos removidos após o laboratório.

Não adicione screenshots ou URLs fictícias.
